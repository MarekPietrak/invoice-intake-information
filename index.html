Invoice Intake Automation

A private Gmail-to-Drive workflow that reviews document attachments and files accepted invoices by their issue month.

Read the privacy notice ↗How it works ↓

No public registration, account connection, or document upload is offered on this website.

Document processing

From attachment to archive

  1. 01

    Gmail

    The authorized account’s configured incoming messages are checked for PDF and image attachments.

  2. 02

    Local processing

    A self-hosted n8n workflow checks files, extracts usable PDF text, or renders PDF pages locally when needed.

  3. 03

    OpenAI API

    Document text or images are sent to OpenAI for document classification and, for likely invoices, field and issue-date extraction.

  4. 04

    Google Drive

    Original files that pass the configured checks are archived in the account owner’s selected Drive location by invoice issue month.

Scope

One account owner.
A self-managed workflow.

This automation is intended for the operator’s own authorized Google account. Processing runs in a separately managed n8n installation—not on this public website.

Google permissions are granted through Google’s OAuth consent flow. This website never asks for a Google password or an invoice.

Review

Automated checks,
not an accounting guarantee.

Documents with uncertain or conflicting classification or date evidence are held for review rather than automatically filed.

AI output can still be wrong. The account owner remains responsible for checking documents, classifications, and archive destinations.
